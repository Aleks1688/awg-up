# awg-up
скрипты для автоматической установки AWG ver 3.1 и ver 2.0

########################################

запуск скрипта для установки AWG ver 3.1
########################################

curl -fsSL https://raw.githubusercontent.com/Aleks1688/awg-up/main/awg-up.sh -o awg-up.sh

bash awg-up.sh

awg-up.sh — одноразовый VPS -> AmneziaWG 3.1 сервер + готовый конфиг для роутера.
Обёртка над https://github.com/bivlked/amneziawg-installer (Ubuntu 24.04).
Запускать от root на ЧИСТОМ VPS. Скрипт сам понимает, на каком он шаге:
  - установка ещё не завершена -> запускает установщик (он перезагрузит сервер 2 раза)
  - установка завершена        -> создаёт клиента и печатает конфиг
То есть после каждой перезагрузки просто запускаешь ту же команду снова.
Переменные (необязательно):
  CLIENT_NAME=beryl   имя клиента (по умолчанию beryl)
  AWG_PORT=443        UDP-порт сервера (по умолчанию выбирает установщик)

######################################

запуск скрипта для установки AWG ver 2
######################################

curl -fsSL https://raw.githubusercontent.com/Aleks1688/awg-up/main/awg2-up.sh -o awg2-up.sh

bash awg2-up.sh

awg2-up.sh — одноразовый VPS -> AmneziaWG 2.0 сервер + конфиг для роутера (GL.iNet Beryl 7).

Зачем отдельный скрипт: роутер знает только AWG 2.0, а приложение Amnezia и
установщик bivlked теперь выдают 3.x (HeaderProtectionKey), с которым роутер
не соединяется. Здесь используется установщик wiresock/amneziawg-install:
на чистой установке он остаётся на протоколе 2.0, а 3.x включается только
отдельным флагом, которого мы не передаём.

Запускать от root на ЧИСТОМ VPS (Ubuntu 24.04 или Debian 12/13).
Если после установки сервер надо перезагрузить — скрипт скажет, тогда
просто запусти его ещё раз после перезагрузки (он сам продолжит).

Необязательные переменные:
  AWG_PORT=443       UDP-порт сервера (по умолчанию установщик берёт случайный)
  AWG_SKIP_HASH=1    не проверять хеш установщика (если автор его обновил)
